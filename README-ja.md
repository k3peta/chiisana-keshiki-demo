# 小さな風景 — iPhone向け検証候補（未公開）

HTTPSで配信する静的アプリです。URLをSafari等で開いて遊ぶ方式を準備しています。インストールやAI APIは使いません。まだ公開URLはありません。iPhone実機・Safariでは未検証です。

1. 初期の4×6m床を使います。木の床は「床を用意」から別タブで開始。
2. 「使えるアイテムを選んで置く」で画像を1回押すと、家具1点が床に置かれ選択されます。同梱21モデルは追加登録不要。
3. 1本指で素材を選び、移動の矢印／回転のリングをドラッグ。背景の1本指ドラッグは視点回転です。
4. 2本指を広げると拡大、閉じると縮小。同じ方向に動かすと視点を回します。途中で2本指にすると進行中の1本指操作を取り消します。3本以上ではその視点操作を取り消し、全部の指を離してから再開します。
5. 「置いたアイテム一覧」で複製・作品から削除。登録は残ります。Undo/Redoで戻せます。タッチ端末では小さな浮動削除ボタンを非表示にしました。
6. 自分のZIP/GLBは「追加アイテムを登録」→ファイル選択→「メニューを再構築」。生成画像を押して配置します。未知素材の再配布権は自動認定しません。
7. 「場面を保存」でJSONをファイルへ保存。追加素材の元ZIP/GLBも保持。JSON読込みで再開します。ブラウザ記憶は補助で、削除や容量制限で失われる場合があります。

ページのスクロールは作品枠の外で行ってください。ページの拡大機能は制限していません。複製・削除・サイズ数値などは右一覧のボタンから操作できます。

## 条件と制限
WebGL2、Pointer Events、Web Crypto、ファイル読込、ZIP用DecompressionStream(deflate-raw)を必要とします。特定Safari版での動作保証はまだありません。公開HTTPSページが用意されれば受取人にPythonは不要ですが、ZIP内HTMLの直接タップ起動は保証しません。ローカル確認は既存の静的HTTP環境が必要です。
初回は通信が必要。モデルは使用時だけ読み込み、画像は遅延読込みします。未取得素材やページ自体のオフライン再起動は保証しません。サーバー側の計算、作品アップロード、AI呼び出しはありません。配信業者のアクセスログは別です。
最大40配置、ZIP/GLB上限は画面表示の通り。iPhoneのメモリで40点を保証する値ではありません。使用済みGPUモデルの自動解放は未実装です。大量素材は段階的に追加してください。
新しい2本指操作は編集画面のみ。作品HTMLビューアのタッチ改善は未実施。マウス操作、Shift30度、キーボード、旧JSON形式は維持。候補専用ブラウザ記憶のため旧版ライブラリは自動移行しません。元ファイルを再登録できます。
